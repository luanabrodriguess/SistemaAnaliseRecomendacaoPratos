1) Baixar e instalar Python no computador.

2) Baixar e instalar PyCharm no computador.

3) Acessar o PyCharm.

4) File -> Open para realizar a abertura do projeto.

5) Para a correção de possíveis erros, essas são as bibliotecas que o projeto está
utilizando:

PARA ATUALIZAR O PYTHON DE 25.1.1 PARA 25.2, digite no terminal (TERMINAL NO PYCHARM):

python.exe -m pip install --upgrade pip

6) Após atualizar digite no terminal para instalar as bibliotecas:

pip install openpyxl
pip install scipy
pip install matplotlib
pip install numpy
pip install pandas

7) Para a verificação das instalações realizadas, digite:

pip list

Se as bibliotecas instaladas forem exibidas acima, tudo estará conforme esperado.
