Para Rodar o arquivo "MachineLearning_Final.py"
1) Arquivo de Dados: O arquivo Dados.xlsx deve estar na mesma pasta do seu arquivo Python
(MachineLearning_Final.py).

Passo a Passo de Instalação e Execução
O processo a seguir deve ser feito no Terminal (Terminal do PyCharm).


2) Instalar as Bibliotecas Essenciais
Você precisa instalar as bibliotecas que o seu código usa (Pandas, NumPy, Scikit-learn, Matplotlib e SciPy).
 A maioria delas é citada no seu "pip list"

Comando Único de Instalação:

pip install pandas numpy scikit-learn matplotlib scipy openpyxl.
